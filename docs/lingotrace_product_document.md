# LingoTrace 产品与能力说明

## 1. 产品定位

LingoTrace 是基于 Obsidian、由 AI Agent 驱动的外语学习工作流引擎。它不是课程或预制词库，而是把用户真实接触的文章、播客、视频和课堂材料转化为可追溯、可复习、可输出的私人学习系统。

产品有两条入口：普通学习者从上游 GitHub 的单句 Agent 协议完成最小运行时和第一个 Vault；希望增加语种或功能的开发者使用完整 fork/branch/PR 流程，但其日常学习环境仍复用同一 Vault 初始化。

当前完整支持日语和英语。每个 Vault 只绑定一种目标语言；公共运行时、语言包和私人 Vault 相互分离。

## 2. 学习闭环

```text
真实材料
  -> 听力笔记或来源笔记
  -> 词汇、语法、发音和错题卡
  -> 间隔复习
  -> 口语语块和主动输出
```

用户通过自然语言与 Agent 协作，不需要了解内部函数、数据结构或写入模式。Agent Skill 负责识别意图，确定性运行时负责路径、查重、状态和写入保护。

## 3. 核心能力

### 3.1 听力笔记

将本地音频、视频或可审计转写整理为泛听笔记或精听材料。精听模式可以引用真实音频切片；双 ASR 存在差异时由 Agent 在同一任务中完成受约束合并，低置信度片段继续阻止最终写入。

Japanese 可以使用假名和音调重音提示；English 使用 `en-US` 默认转写区域，不加载日语词典，并提取可复用的英语语块。

### 3.2 来源笔记

将文章、网页、视频内容、转写或用户粘贴文本整理为有明确来源的学习笔记。来源笔记保留材料出处和后续卡片引用关系，不在没有用户意图时自动制造大量复习卡。

### 3.3 复习材料

维护词汇、语法、错题和发音卡。创建前先查重，先检查 Focus 层，再检查 Base 层。新词进入 Focus；完成长期复习后可以下沉到 Base。

核心拥有通用 SRS 外壳，语言包拥有语言特有字段：

- Japanese：假名、音调重音、汉字差异等；
- English：IPA、单词重音、英英释义、搭配、英语发音问题等。

### 3.4 口语卡与语块

把用户确认过、真正希望说出口的表达转为主动输出练习。听力任务只提取候选语块，不在同一任务中直接晋升为口语卡；用户完成离线审核后再明确要求转入口语库。

### 3.5 每日复习结算

复习状态保存在卡片 Frontmatter 中。结算读取当天完成情况，推进下一次复习日期，处理延期和完成状态。明确的结算请求执行：

```text
preview -> apply -> second preview
```

系统不维护平行的复习状态 JSON 数据库。

### 3.6 总训练看板

语言包提供 Obsidian Base 视图，汇总今天和下一复习日的词汇、语法、错题、发音、听力和口语训练。视图读取普通卡片 Frontmatter，不生成第二套状态快照。

## 4. 数据与运行边界

公共仓库保存程序、语言包、模板和测试。私人 Vault 保存配置、笔记、媒体和复习状态。日常学习以 Vault 为工作区，运行时通过 `.lingotrace/runtime-connections/` 从 Vault 外部加载。

同一个运行时可以服务多个 Vault，但一次任务只能写一个 Vault。所有写入必须通过 Vault 上下文、能力检查、路径角色和 core 写入保护。

## 5. 人与 Agent 的分工

Agent 适合：

- 理解用户意图；
- 整理材料；
- 判断表达价值和自然度；
- 解释语言现象；
- 在受约束证据内处理 ASR 差异。

确定性代码负责：

- 路径边界；
- 查重与路由；
- SRS 日期和状态；
- 文件冲突；
- 必填字段和链接验证；
- 预览、写入与结果报告。

用户保留对已有笔记、人工筛选内容和复习状态的最终控制权。

## 6. 非目标

LingoTrace 当前不提供：

- 零基础课程体系；
- 公共教材和商业媒体内容；
- 云端账号或多人同步服务；
- 无需 Agent 的独立图形客户端；
- 在单一 Vault 中混合多个目标语言；
- 绕过用户确认的大规模自动改写。
