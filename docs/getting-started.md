欢迎来到 LingoTrace！如果你正准备将外语学习真正融入日常生活，而不再是仅仅为了应付考试，那么你来对地方了。

本指南是专门为你——普通外语学习者——准备的。这里没有晦涩的代码、没有复杂的内部逻辑说明，只有最真实的学习场景和最直觉的交流方式。

# 写在前面：抛弃死记硬背的孤岛

## 为什么需要 LingoTrace？

传统的语言学习往往是一个“孤岛模型”：你在 App A 里刷无聊的词汇题，在 App B 里看剧，在 App C 里记笔记。最后，你学到的词汇依然无法在开口时调用。

LingoTrace 提出的是一个**“漏斗与发酵模型”**：
所有的学习材料都来自于你真实的**输入素材**（你看的油管视频、听的日文播客、读的外网新闻）。遇到生词或好句，你的“私人助理”会帮你提炼成**结构化图谱**。随着时间的推移，这些经过你大脑反复处理的信息，最终会被打造为你能脱口而出的**主动口语输出**。

## LingoTrace 与传统工具的区别

- **对比背单词 App (如多邻国、百词斩)**：传统 App 塞给你的是脱离语境的干瘪词汇。而在 LingoTrace 中，你的词库 100% 来源于你亲自看过的文章或听过的播客。每一个词，都带着你当时的温度和一手语境。
- **对比传统闪卡 (如 Anki)**：在 Anki 里，最痛苦的是“制卡”——排版、配图、写 HTML、复制粘贴释义。在 LingoTrace，这一切都被 AI 接管。你只需要动动嘴：“帮我把这个词做成复习卡”，所有的排版和结构化工作瞬间自动完成。
- **对比普通笔记软件**：普通的笔记写完就落灰了。LingoTrace 拥有一套极其严谨的“状态机”，它会像一个严格的教练，在每天的训练看板里安排好你该复习的内容，并在你彻底掌握后自动让它“毕业”。

# 架构与角色分工：Agent 与 Obsidian 如何协同

很多初学者会疑惑：“我既然已经有了 AI Agent 助理，为什么还需要在电脑上安装 Obsidian？”

理解两者的分工是流畅使用 LingoTrace 的关键。它们并不是替代关系，而是最佳拍档：

- **🧠 AI Agent（你的幕后秘书 / 大脑）**：
  负责所有复杂的计算、文本抓取、语法解析、音频切片、建卡排版与复习周期结算。你通过聊天框给它下达自然语言指令。
- **📦 Obsidian Vault（你的本地数据中心 / 仓库）**：
  你所有的学习笔记、卡片和音频都保存在本地纯文本 Markdown 文件中，数据永远属于你，不依赖任何云端封闭数据库。
- **🖥️ [Obsidian 桌面端](https://obsidian.md)（你的专属视觉看板 / 前端播放器）**：
  作为系统的**官方图形界面（GUI）**，Obsidian 承担了人眼阅读与交互的最佳体验：
  1. **全景训练看板**：通过 Obsidian Base 视图直接查看今天该复习什么卡片，无需手动翻找；
  2. **点读音频切片**：在精听笔记中直接点击音频片段进行原声播放与影子跟读；
  3. **双链知识网络**：点击卡片上的 `[[来源笔记]]` 瞬间回溯当时的完整上下文语境。

## 极简日常操作动线对照表

你在日常学习中如何与这两个工具打交道？只需遵循以下简单动线：

| 学习阶段 | 在哪里操作 | 你的具体动作 | 背后谁在工作 |
| --- | --- | --- | --- |
| **1. 输入与建卡** | AI Agent 聊天窗口 | 丢入文章、播客或视频，说“整理成笔记”或“把这个词加入复习” | Agent 提取重点、解析语法、生成标准本地 Markdown 笔记与卡片 |
| **2. 沉浸阅读与跟读** | Obsidian 桌面端 | 打开刚刚生成的学习笔记，沉浸阅读，点击音频切片进行影子跟读 | Obsidian 原生编辑器与多媒体播放组件 |
| **3. 看板自测与复习** | Obsidian 桌面端 | 打开 `Total Training Dashboard` 看板，按艾宾浩斯记忆表逐一自测卡片 | Obsidian Base 数据库视图动态筛选并呈现今日到期内容 |
| **4. 推进周期与结算** | AI Agent 聊天窗口 | 对 Agent 说出“今天复习完了，帮我结算” | Agent 扫描卡片 Frontmatter，更新下次复习日期并汇报结算结果 |

# 启程准备：唤醒你的私人助理

## 什么是 AI Agent？

在这个工作流中，你不再是“操作者”，而是“指挥官”。你需要一个具备 **Agent (智能代理) 能力**的工具来驱动你的 Obsidian 仓库。
请在本地部署或者使用以下任意一款带有 Agent 能力的 AI 工具：
**Codex、Claude、Hermes Agent、OpenClaw、Trae Work、QoderWork 或 WorkBuddy**。

初始化后，让 Agent 以你的 Obsidian 学习库（Vault）为日常工作区，然后你就可以直接用人话给它下达指令了。LingoTrace 程序仓库保留在 Vault 外部，初始化器会为当前操作系统保存运行时连接。

## 第一次安装：把一句话交给 Agent

你不需要先下载仓库或学习命令行。把下面整句话发给能操作本机文件和命令的 Agent：

> 请阅读并严格执行 https://raw.githubusercontent.com/feiyanqiqiao/LingoTrace/main/docs/learner-agent-setup.md ，帮我安装 LingoTrace 并初始化第一个学习 Vault。

Agent 会让你选择英语或日语，建议 Vault 和运行时位置，检测 Python、Git、Obsidian 桌面客户端和 ListenKit；任何安装、下载或写入前都会先征求你的同意。

> 💡 **关于组件依赖说明**：
> - **[Obsidian 桌面客户端](https://obsidian.md/download)**：**必备组件**。要用好 LingoTrace，必须安装 Obsidian 作为官方图形界面（GUI），所有的 `.base` 数据库看板与音频切片点读跟读均在其中运行；
> - **ListenKit**：**可选组件**。负责音频下载与语音识别（ASR）。如果不安装，仍可完整使用文本阅读、生词提炼、口语卡制作与每日复习结算功能。

安装 ListenKit 时，Agent 会先给出当前系统的建议目录，也允许你指定其他绝对路径。确认后的目录会保存在当前设备的 LingoTrace 应用数据目录，英语、日语和未来语种 Vault 共同使用。只有某个 Vault 明确需要不同版本时才保存单独覆盖。以后如果目录被移动或删除，Agent 会让你选择重新安装，或者指定已经安装好的 ListenKit，不会凭任意目录名猜测。

完成后，在 Codex 等 Agent 中打开 `LingoTrace-English` 或 `LingoTrace-Japanese` 作为日常项目工作区；同时在 Obsidian 桌面端中将该目录作为“打开本地库（Open Vault）”打开。程序运行时放在 Vault 外部，只用于更新和提供底层能力。

以后每天第一次开始学习时，Agent 会检查一次 LingoTrace 正式版有没有更新。如果有，它会用中文告诉你主要新增或修复了什么，再问你要不要现在更新。你完全可以不回答或说“先不更新”，Agent 会继续处理今天的学习内容，同一天不会反复追问。

如果你用的是正式版，明确同意后 Agent 才会安全更新；如果你连接的是自己 fork、改造过的版本，Agent 不会擅自拉取或合并，而会请你到开发仓库自行处理，避免破坏个人改动。

如果你把 Vault 和运行时同步到 Windows、macOS 或 Linux 的另一台设备，Agent 会先查找当前系统保存的运行时路径。找不到时，它会询问你本机的 LingoTrace 目录，验证后只追加当前平台连接，不覆盖其他系统的路径。详细说明见 [Vault 初始化与跨平台运行时连接](vault-initialization-and-runtime-connections.md)。

如果你以后想修改程序、增加语种或向上游贡献，不要在私人 Vault 中直接改运行时；另建完整开发仓库，并把 [开发者初始化协议](developer-agent-setup.md)交给 Agent。

## 目前支持的语种

- **日语 (Japanese)**：🌟 官方全功能支持！包括播客泛听/精听打轴、文章阅读、语法解析、口语发音卡、每日复习看板与结算。
- **英语 (English)**：🌟 官方全功能支持！包括播客泛听/精听、文章阅读、词汇/语法/错题卡、英语口语语块、单词重音与音素对比卡、每日复习看板与结算。

> - 语言包架构与规范：参考 [新语言包贡献指南](multilingual/language-pack-contributor-guide.md)；

# LingoTrace 的一天：你的私人语言助理

为了让你直观地感受这套工作流，让我们来想象普通但沉浸的“LingoTrace 的一天”。不要去想怎么编写指令，只需想象你要对你的 AI 助理说什么。

## 🌅 场景 1：早晨通勤的播客（沉浸输入）

早上挤地铁时，你在手机上听到了一段非常有意思的日文播客，或者在 YouTube 看到了一段 VLOG。你想把它作为今天的精听材料。

你只需要把音频文件或链接丢给你的 Agent，并对它说：

> 🗣️ **“请把这段音频做成精听稿。”**

**AI 助理会怎么做？**
它会默默地在你的学习库里新建一篇听力笔记，自动切片打好时间轴，提取出双语对照。当你坐到工位上打开 Obsidian 时，一份排版精美、随时可以点击重放的精听材料已经准备就绪。

## ☕ 场景 2：午休的阅读（提炼与建卡）

午休时，你读到了一篇英文科技博客，或者一篇日文新闻。里面有几个生词和有趣的语法搭配，你不想读完就忘。

你可以把文字丢给 Agent，并对它说：

> 🗣️ **“帮我把这篇材料整理成学习笔记。”**
> 🗣️ **“把文中的 'ubiquitous' 和 'empower' 这两个词加入复习。”**

**AI 助理会怎么做？**
首先，它会为你建立一篇“来源笔记”（Source Note），保留原文的追溯链接。接着，它会自动从文中提取那两个生词，查好音标（IPA/重音）、英英释义、常见搭配，然后生成两张完美的“词汇复习卡”塞进你的生词本里。你全程不用动一次复制粘贴。

## 🌃 场景 3：晚上的闪念（主动输出）

晚上在家里回味今天的素材时，你发现新闻里有一句极其地道的表达：“It goes without saying that... / 言うまでもなく…”。你希望以后在跟老外交流时，这句话能张口就来。

你对 Agent 说：

> 🗣️ **“这句话很实用，帮我做成口语卡。”**

**AI 助理会怎么做？**
它会专门为你生成一张用于“张口说话”的肌肉记忆训练卡（Speaking Card）。这张卡的重点不再是让你认识它，而是强迫你在未来的复习中，看到母语提示就能瞬间反射出外语。

# 睡前的仪式：看板与结算

学习最怕的是虎头蛇尾。在 LingoTrace 里，你每天的睡前仪式感，都由一个全局仪表盘来承载。

## 📊 全景训练看板 (Total Training Dashboard)

打开你的 Obsidian 桌面端，你会看到一个名为 `Total Training Dashboard` 的表格视图。这是 LingoTrace 的中枢神经。
这里汇集了你今天需要复习的词汇、需要造句的语法、需要纠正的发音错误。它会严格按照艾宾浩斯记忆曲线为你排序。

## 💤 如何结束一天的训练？

当你在 Obsidian 看板中完成了当天的所有口头或默写自测后，你需要让系统“滚轮”往前转动。不要去手动改日期，你只需要切回 Agent 聊天窗口，说出那句如同魔法咒语般的话：

> 🗣️ **“今天复习结束了，帮我结算。”** （或者 **“更新总训练表”**）

**AI 助理会怎么做？**
它会迅速扫描全库，帮你把所有今天复习过的卡片推向下一个记忆阶段，算出下一次该复习的具体日期，并把逾期未复习的卡片进行降级惩罚。结算完成后，它会给你一份详细的复盘报告（比如“今天晋升了 5 张卡，延迟了 2 张卡”）。

## 🎓 掌握机制 (Mastery)

当一张卡经历完整的 8 个复习阶段后，AI 会在结算时把原卡标记为 `Mastered（已掌握）`。它会离开每日总训练，但仍保留在素材库的“已掌握”视图中；系统不会再制造一张重复的基础词卡。

新保存的听力、生活口语和语块会先进入素材库，不会自动挤进每日复习。你准备开始练习时，只要告诉 Agent“把这些素材加入复习”；退出队列也不会丢失已经积累的阶段。

# AI 沟通守则与避坑指南

当你拥有了一个如此强大的私人助理，你需要了解它的一些“工作原则”。

## 🛡️ AI 是高度防御性的

不用担心 AI 会搞乱你的笔记。LingoTrace 的系统底层有一套极严的“护栏”。

- 如果你要修改或覆盖一篇**你曾经手工整理过**的笔记，AI 会停下来，主动问你：“这篇笔记已经存在了，您确定要我覆盖它吗？”
- 如果你发了一段音频让它做听力笔记，但系统找不到转录工具，AI 会诚实地告诉你：“抱歉，缺少音频处理工具，我无法开工。”

## 🗣️ 像对人说话一样提要求

你可以包容它的偶尔迟钝，也可以用你习惯的方式下指令。你可以说“结算复习”、“今天学完了”、“帮我过一下当天的卡”，Agent 底层的智能大脑都能准确识别出你的真实意图。如果不确定，它会礼貌地追问你一句。

所以，放轻松。不要背诵指令代码，**直接开始你的语言沉浸之旅吧！**
